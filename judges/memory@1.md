# memory@1 (DRAFT, not frozen, not admitted)

Status: draft rubric for agent-memory cases (cross-session preferences, withdrawn instructions), advisory only. Written for the reference adopter's memory suites. Not frozen, SHA-256 not committed, so it cannot enter admission (§4.3).

Pointwise, one dimension, `unknown` always offered, system and model names never shown (§4.2).

Labels: `pass` if the reply does what the reference says about what the founder told the agent earlier: it follows the most recent instruction, keeps a scoped exception scoped, no longer applies what was withdrawn, cites a recorded reason as recorded (or says none was recorded), and never states as remembered something nobody said. `fail` if it applies a stale or withdrawn preference, over-applies an exception, or invents a reason or a memory. `unknown` if the transcript does not allow a judgement.
